# Support Snapshot (phone/web app)

Support Snapshot by Teachers Best Friend is a private, offline view of each student's accommodations at a glance for teachers.

- **Private by design:** no account, no server, no tracking. Everything you enter is saved only on your own device (browser storage). Nothing is uploaded.
- **Works offline:** after the first visit, a service worker keeps the app available with no internet.
- **Install on iPhone:** open the link in Safari, tap Share, then **Add to Home Screen**.
- **Back up weekly:** Setup → Save backup file.

This repository contains only the static app files. Demo data inside the app uses made-up names.

Support Snapshot is a teacher reference, not an official record.
